# Internxt Drive Clone - Prueba Técnica Frontend

Clon funcional de la interfaz de Internxt Drive desarrollado con React, TypeScript y Tailwind CSS.

## 🚀 Cómo ejecutar el proyecto

1. Clonar el repositorio: `git clone https://github.com/PAMABA261/internxt-drive-clone.git`
2. Instalar dependencias: `npm install`
3. Iniciar servidor de desarrollo: `npm run dev`
